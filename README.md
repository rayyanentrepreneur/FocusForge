# FocusForge 🎯
### Build focus. Track progress. Get better every day.

FocusForge is a student productivity web app designed to help students plan their study sessions, manage daily tasks, track distractions, and understand their study habits.

The goal is simple: make studying more intentional and help students improve their focus over time.

## ✨ Features

- **📋 Task Management** — Organize daily study tasks and track completion.
- **⏱️ Focus Timer** — Use focused study sessions to stay on track.
- **🧠 Distraction Tracking** — Record distractions and become more aware of your habits.
- **📊 Progress Dashboard** — View study statistics and monitor your progress.
- **📈 Study Analytics** — Understand your productivity and study patterns.
- **💾 Data Persistence** — Save supported app data locally in your browser.
- **📱 Responsive Design** — Use the app across desktop and mobile devices.

*Features listed above describe the project goals. Check the current implementation to confirm which features are available.*

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- CSS / Tailwind CSS, depending on the implementation
- LocalStorage for local data persistence

## 🚀 Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/rayyanentrepreneur/FocusForge.git
   ```

2. Navigate to the project directory:

   ```bash
   cd FocusForge
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Production Build

To build the app for production:

```bash
npm run build
```

## 🎯 Why FocusForge?

Students often struggle to manage their time, avoid distractions, and maintain consistent study habits. FocusForge aims to bring task planning, focus sessions, and productivity tracking into one simple interface.
